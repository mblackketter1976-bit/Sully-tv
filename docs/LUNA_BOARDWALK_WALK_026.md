# Luna boardwalk walk 01

Six-second illustrated four-legged walk study, 1280×720, 24 fps/144 frames. Luna advances across a matching Old Sacramento twilight boardwalk, with ground shadow, near-post foreground occlusion, restrained distant river movement and original synthesized paw taps/ambience. No speech or narrator; Luna's permanent voice and the female Rook direction remain unchanged.

Eight new authored walk drawings were generated in a sheet from the accepted immersive scene reference. Six were selected in order 0,1,2,5,6,7: forward near-forepaw contact, under-shoulder support, backward support, opposite-leg support, lifted swing, forward reach. The other two were omitted for repeated/poorly sequenced poses. Key timings 0,6,10,14,18,22 in a 24-frame repeating cycle. RIFE v4.9 supplies the other 18 computed frames; those are inferred frames, not 18 new drawings. Local U2netp extracts white fur without white color-key removal. Blue near-eye registration stabilizes horizontal head placement; common support-line placement uses only translation, never head mesh compression. The first satchel-based alignment was rejected for head drift.

A matching empty boardwalk plate was generated from the same scene reference by removing the actors/crate and exposing the walking path. Built-in image tool prompts requested identical snow-white merle coat, blue eyes, smushy face, black paw/shield bandana and olive satchel, clear four-legged gait poses on white; and a matching empty drawn twilight boardwalk. No Runway service or assets were used. Original generated sheet and plate retained with this package.

The first practical walk proof is not a verified no-slip quadruped rig. Travel speed 125 pixels/second is a visual approximation of the stride; paws can still slide and generated markings/limb proportions can vary. Foreground overlap and contact shadow integrate the character, but this is a short walking study rather than a finished production shot. All 24 cycle drawings/intermediates and sampled final frames inspected; full video/audio decode and frame count verified. No realtime playback/listening claim.

Reproduction source: studio/scenes/boardwalk_walk_01/build_walk.py in the Luna GitHub branch. This folder is expected beside luna-finished-scene-10s-v01/models (verified RIFE/U2netp weights) and luna-environment-motion-v01/environment-ambience.wav. Requires NumPy, OpenCV, Pillow, soundfile, ONNX Runtime, FFmpeg. ORT_DISABLE_TELEMETRY=1 is set before import and runtime telemetry is explicitly disabled. Model licenses/provenance remain with the earlier Cookie Caper asset package. The package contains image assets, derived 24-frame cycle, audio and verification; source is maintained in GitHub rather than duplicated here.
