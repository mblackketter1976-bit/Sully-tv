# Working principles — Sully TV and future projects

This document captures the owner's standing collaboration preferences. Read it before making product decisions or editing this repository.

## Non-negotiable mission
"Create the simplest, most reliable experience possible, investigate why competing products struggle, find legal free alternatives, and implement the best solution."

Apply this to every feature, bug fix, design choice, and product discussion. Aim to outperform established products on usability, reliability, discovery, personalization, and ingenuity—not merely copy them.

## Working method
1. Understand the real user goal, not just the literal requested UI change.
2. Investigate competitors' friction, relevant technical documentation, and lawful free options.
3. Challenge assumptions; suggest a better path when justified.
4. Favor intuitive, accessible, fast experiences across mobile, desktop, and TV.
5. Implement directly in the existing GitHub repository when authorized. Preserve all working features.
6. Test or inspect results wherever possible. Clearly distinguish code changes from verified end-to-end behavior; never promise a stream works without actual playback confirmation.
7. Avoid needless troubleshooting steps, repeated manual copy/paste, progress reports, or costs for the owner.
8. Respect copyright, licenses, privacy, and service terms. Free-to-watch is not automatically free-to-redistribute; never bypass access controls or misrepresent rights.
9. Maintain useful Git history and minimize regression risk.
10. Iterate until the product feels delightful, especially for young children and nontechnical viewers.

## Cost constraint
Zero recurring cost. Prefer genuinely free software, hosting tiers within their limits, permitted APIs, public-domain or properly licensed media, and official embeds. If a desired feature requires payment, seek a genuinely free legal redesign or explain the tradeoff.

## Product specifics
Sully TV is a streaming discovery/player web application. Keep Kids TV picture-first and English by default with a single recognizable Spanish-language switch. Don't populate the UI with knowingly broken channels. Preserve existing channels, DVR, Luna content, and Michele's Murder Mystery Channel.

## Continuity
This file is a durable project brief, not a substitute for checking current code, current licensing, and the user's latest instructions. Update it when the owner changes these principles.
