# Luna opening animation 01

Ten-second quiet opening performance by the river, 1280×720 at 24 fps, with original procedural music and air/water ambience. No dialogue or narrator. Luna's approved permanent voice remains unchanged; The Rook's voice is uncast.

The Rook is now female at the owner's direction. Preserve the majestic existing raven design, iridescent blue-green feather cloak, long beak and silver clasp. Charm, wit and theatrical courtesy drive her schemes. Nicol described the raven as majestically beautiful; gender changes do not require replacing her accepted visual design.

Performance: Luna blinks, glances toward the cookie and leans in with curiosity; The Rook gives a small nod and offers the cookie. River reflections, distant tree tips and flowers move independently. The crate, planted paws, planted hand and foreground are pinned before encoding. This is a restrained 2D performance study using localized deformation and registered eye-expression drawings, not full-body redrawn cel acting or a completed episode opening.

Two expression edit targets were produced with the built-in image tool from the accepted environment frame: (1) close only both characters' eyelids, keeping composition and contacts; (2) Luna looks toward the cookie and Rook raises her brow, retaining the same characters and framing. Only masked eye regions from these images enter the final sequence; other generated differences are excluded. SIFT estimates a single global similarity placement. RIFE v4.9 supplies intermediate eye patches; source drawings remain at exact endpoints. The project assets retain original and donor drawings. No Runway service, credits or code.

Reproduction: place this directory beside `luna-environment-motion-v01` and `luna-finished-scene-10s-v01`, retaining the prior environment assets/renderer and verified RIFE model. Run `ORT_DISABLE_TELEMETRY=1 PYTHONPATH=/tmp/luna-2d-deps:/tmp/luna-pilot-deps python3 build_opening.py`. Required: NumPy, Pillow, OpenCV, SciPy, soundfile, ONNX Runtime and FFmpeg. Telemetry is disabled before importing ONNX Runtime and through its runtime opt-out. Existing model license/provenance is retained in the Cookie Caper asset package. This package does not duplicate models or repository-backed code.

Verification: registered expression/gesture proof samples inspected, raw planted contact/static pixel assertions on every frame, 240-frame H.264/AAC export and full A/V decode. No realtime playback/listening claim. See verification.json for final file hash and registration details.
